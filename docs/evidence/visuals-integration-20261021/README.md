## Integration fixes

- **"Today" is UTC on both engines.** PGlite followed the host zone (`Etc/GMT+5` here) while the
  Postgres suite ran in UTC, so `chamber.composition.asOf` (and who counts as currently serving)
  differed between engines for hours around midnight. PGlite sessions now `SET TIME ZONE 'UTC'`
  (failure handled, not an unhandled rejection), and the Postgres pool sends `TimeZone=UTC` as a
  startup option. Tests: `packages/db/test/client.test.ts` (UTC, broken data dir; the
  broken-dir test fails without the fix), `test-pg/pool.pgtest.ts` (interactive and batch
  pools report UTC).
- **Postgres suite:** the full-pipeline test runs the census fixture with fixture-sized
  minimums (the full-file truncation guard stays tested in `census-boundaries.test.ts`); the
  read-only sweep passes a slug to `districts.shape`.
- **Profile header at 320 px:** a long single-word surname scrolled the page 2 px sideways next
  to the portrait. Below 640 px the eyebrow and name now span the full width and the portrait
  sits beside the lines under the name.
- **Name formatter (review follow-up):** a dotted initialism at the start of the given names
  ("J.D.") is the name, not the J.D. degree; when nothing is left of the given names
  ("LAM, HON", "SCHOLTEN, JD") the filed order and every word are kept; given-name initials
  with no vowel ("TJ", "KJ") stay in capitals. Over the 4,379 real 2026 names, 6 outputs changed,
  all improvements (for example "Tj Baker" to "TJ Baker", "Tracy L. Mft Limon" to
  "Tracy L. MFT Limon").
- Docs: stale decision citations, a Races heading in CAPABILITIES, the `races.get`
  `not_found` wording in API.md, a dead check removed from `races.get`.

## Independent review (H3)

A read-only reviewer covered the races review fixes (including the regenerated `candidate`
migration), the integration fixes and both merge resolutions. Verdict: no blockers; four
should-fix items (unhandled rejection in the PGlite time-zone call, Postgres not pinned to
UTC, the feature-branch database upgrade path, the formatter dropping or relabelling a given
name), all fixed above. Confirmed fine: journal and snapshot chain 0000-0008, decision IDs
without gaps or duplicates, merged registries, seed wiring and route lists with nothing
dropped or doubled, the combined member profile.

Not changed (noted by the reviewer, low impact):
- `races.list` loads unplaced registrations on every unfiltered call, including the default
  `/races` page, which does not show them.
- If a future cycle is ingested before the next Congress's terms exist, every House
  registration of that cycle would be listed as unplaced.
- The web app keeps its own copy of the registration notice (equality is tested).
- The default `/races` page is 149,487 B on real data against a 150,000 B budget; the e2e
  size check runs on seed data only.
